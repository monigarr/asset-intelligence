# Asset Intelligence (live demo)

Evidence-linked inspection intelligence for infrastructure assets. Upload a field
photo with a note; the Meta AI pipeline (SAM segmentation, Muse Spark vision and
reasoning, Muse Wonder planning) returns observations, discrepancies, and a
recommended next step with cost and latency metering.

- Source: https://github.com/monigarr/asset-intelligence
- Built by Monica Peters for the Meta Global AI Developer Hackathon:
  https://dev.meta.ai/events/global-hackathon
- Request an API key: monica@manageassets.net
- Contact: https://manageassets.ca/contact/

Demo data is ephemeral: inspection history resets when this Space restarts.
